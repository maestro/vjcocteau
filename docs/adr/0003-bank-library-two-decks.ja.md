# Bank は約30個のライブラリとして持ち、2つの Deck にロードして混ぜる

Bank を32個のライブラリとして持ち、そのうち2つを Deck A と Deck B にロードして Crossfader で混ぜます。動画をデコードするのは Deck にロードされた2つの Bank(最大16本)だけで、ライブラリの残りは動画のパスだけを保持します。ADR 0002 の「Bank は固定2つ」を置き換えます。曲に合わせて使う Bank を多く用意しつつ、再生負荷を2つ分に抑えるためです。画面外テクスチャに合成してから混ぜる構造(ADR 0002)は、そのまま Deck に引き継ぎます。

## Considered Options

- **32個の Bank を同時に再生する**: ロードの待ちはなくなりますが、Layer 8本 × 32 = 256本の動画を同時にデコードすることになり、現実的ではありません。
- **Bank を2つのまま増やさない**: 実装は最も単純ですが、Bank ごとに Clip を組み替える手間が、ライブ前の準備に集中します。

## Consequences

- Bank を Deck にロードしてから最初の映像が出るまでに待ちが生じます。画面に出ていない Deck へのロードは約500msまでを許容します。ロード中も元の Bank の映像は出し続け、読み込みが終わった時点で、Launch Quantize に従って入れ替えます。時間で打ち切ることはしません。途中の状態の映像が出るより、入れ替えが遅れる方を選びました。別の Bank をロードし直せば、ロードを取り消せます。再生できない動画(壊れたファイルなど)は、待ち続けないよう「済み」として数えます。
- 同じ Bank を A と B の両方にはロードできません。Layer の不透明度や Clip の状態が共有されてしまうためです。
- Set は32個すべての Bank の内容を保存します。
- APC mini MK2 での Bank の選び方は、段階3で Controller Layout と合わせて決めます。それまでは画面の UI で選びます。
