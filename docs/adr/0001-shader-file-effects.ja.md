# Effect と Generator はシェーダー + 宣言ファイルで拡張する

Effect と Generator は、Metal シェーダー(`.metal`)とパラメータ宣言(JSON など)をフォルダに置くだけで追加できる方式にします。アプリ本体の再ビルドは不要で、ライブ中のホットリロードにも対応します。ライブ前の調整速度と、ビルド失敗によるライブ事故の回避を優先しました。

## Considered Options

- **Swift プロトコル準拠のプラグイン**: 型安全で多パスやステートを持つ複雑な処理に向きますが、追加のたびに再ビルドが必要で、ホットリロードもできません。
- **動的ロードのバンドル(.bundle)**: 再ビルドは不要ですが、署名やロードの管理が重く、自分専用の用途では過剰です。

## Consequences

- 複数パスやフレーム間ステートが必要な Effect は、シェーダー + 宣言ファイルだけでは表現しにくくなります。必要になった時点で Swift プラグイン方式を追加で検討します。
- 宣言ファイルの形式が Effect の公開インターフェースになるため、後から変更しにくくなります。
