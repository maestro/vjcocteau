# APC mini MK2 の Controller Layout

出典: Akai Professional「APC mini mk2 Communications Protocol v1.0」。実機での確認はまだです。

## 入力

| 操作 | 内容 |
|---|---|
| パッド 8×8 | 列 = Layer 1〜8、行 = スロット(最上段がスロット1)。押すたびに、その Clip の ON/OFF を切り替えます。操作の対象は Edit Deck の Bank です。 |
| 下段のトラックボタン 1〜8 | その列の Layer の ON/OFF |
| 右列のシーンボタン 1〜8 | いまのページの Bank 1〜8 を、Edit Deck にロード |
| フェーダー 1〜8 | Layer の不透明度(Layer 内の全 Clip への倍率) |
| フェーダー 9 | Crossfader(A 側 = 下) |
| `Shift` + トラックボタン 1 / 2 | Edit Deck を A / B にする |
| `Shift` + トラックボタン 3 / 4 | Deck A / B へ Cut |
| `Shift` + トラックボタン 5 | Tap Tempo(2秒以上あくと、叩き直しになります) |
| `Shift` + トラックボタン 6 | Downbeat(押した瞬間を、小節の頭にします) |
| `Shift` + トラックボタン 7 | Launch Quantize の切り替え(なし → 1拍 → 1小節) |
| `Shift` + トラックボタン 8 | Beat Detection の ON/OFF 用に予約 |
| `Shift` + シーンボタン 1〜4 | Bank のページを切り替える(01〜08、09〜16、17〜24、25〜32) |
| `Shift` + フェーダー 9 | Master の明るさ |

フェーダーはすべて Pickup 方式です。物理位置が現在の値に追いつくまで、値は変わりません。

## LED

| 場所 | 表示 |
|---|---|
| パッド | 次の拍を待っているパッドは点滅します(MIDI チャンネル12。実機では未確認です)。割り当てなしは消灯、OFF は暗い(25%)、ON は明るい(100%)。Layer が OFF の列は、さらに暗く(10%)します。色は Deck A が青、Deck B がマゼンタです。 |
| トラックボタン(赤) | Layer が ON のとき点灯。`Shift` を押している間は、Edit Deck(1、2)を点灯し、Cut(3、4)は押している間だけ点灯します(次の拍を待っている間は点滅)。5〜7 は、拍の点滅、小節の頭の点滅、Launch Quantize の状態(なし = 消灯、1拍 = 点灯、1小節 = 点滅)を示します。 |
| シーンボタン(緑) | Deck にロード済みの Bank は点灯、ロード中は点滅。`Shift` を押している間は、いまのページ(1〜4)を点灯します。 |

## MIDI の割り当て(仕様書より)

- パッドのノート: 左下が 0、行ごとに左から右へ増え、最上段の右端が 63
- トラックボタン: ノート 100〜107。シーンボタン: ノート 112〜119。Shift: ノート 122
- フェーダー: CC 48〜56
- パッドの色: ノートオンのベロシティがパレット番号(青 45、マゼンタ 53)。明るさは MIDI チャンネルで指定(ch 1 = 25%、ch 6 = 100%、ch 0 = 10%)
- トラックとシーンのボタン: ベロシティ 0 が消灯、1 が点灯、2 が点滅
